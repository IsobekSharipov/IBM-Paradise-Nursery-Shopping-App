# Paradise Nursery Shopping Application

**IBM Final Project — Paradise Nursery Shopping Application**

Paradise Nursery is a responsive online plant shop built with React, Redux Toolkit, and CSS. Customers can browse houseplants by category, learn about the company, add plants to a cart, and manage their order.

## Project objectives
- Create a landing page with the Paradise Nursery name, background image, description, and Get Started button.
- Create an About Us page with information about the company.
- Display at least six plants in three categories, with photos, names, and prices.
- Add products to a shopping cart using Redux Toolkit.
- Display the cart item count and calculate the order total.
- Allow customers to increase or decrease quantities, remove items, and continue shopping.
- Include a checkout placeholder indicating that checkout is coming soon.

## Planned project structure
- `src/App.jsx` — landing page and application navigation
- `src/App.css` — application styling
- `src/AboutUs.jsx` — company information
- `src/ProductList.jsx` — plant catalog
- `src/CartSlice.jsx` — Redux cart state and actions
- `src/CartItem.jsx` — cart interface
- `src/main.jsx` — application entry point

## Technologies
React, Vite, Redux Toolkit, React Redux, JavaScript, HTML5, and CSS3.

## Development
Once the application files have been added, run:

```bash
npm install
npm run dev
```
